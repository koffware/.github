# KOFFWARE

**Software for business. Built with care.**

We’re a software development company based in Chișinău, Moldova, working internationally. We build custom web applications, backend systems, and integrations, alongside our own products and developer tools.

## What we build

- **Web applications** — practical tools, portals, and business applications shaped around everyday work.
- **Backends & integrations** — APIs, data flows, and connected systems that help software work together.
- **Technical consulting** — support with architecture, existing applications, and choosing a practical way forward.

## Products & open source

- **[PYNTravel](https://pyntravel.com/)** — one place for the whole trip: itineraries, travelers, budgets, expenses, and packing lists.
- **[macdev](https://github.com/koffware/macdev)** — a CLI for local development on macOS. Manage nginx hosts, switch PHP versions, and set up trusted local HTTPS.
